# Methods & reproducibility notes

This short page documents what the README cannot responsibly compress.

### Provenance

The original implementation remains **untouched** at `../DynaCPI-3D-RnD`. Source of the actual V17 3D head and 2D source-calibration: `geometry_v6_20261115/v16_pairenergy_2Danchored_trainonly_20261116/fit_v16_GROUP_OOF_LIGHTGBM_2D_ANCHOR_DIRECT_PAIR_ENERGY_REAL_SHUFFLE_POCKET_FIXED16EP.py` and `geometry_v6_20261115/v17_frozen_original_DynaV5_native_pair_704D_HiQBind_TRAIN349_20261116/fit_v17_ACTUAL_DYNAV5_423D_2D_ANCHOR_PLUS_NATIVE704D_DIRECT_PAIR_4FOLD_TRAINONLY.py`. Frozen external 37-prediction application: `geometry_v6_20261115/v20_new_BioLiP3_37_native_external_labelblind_model_inputs_20261116/predict_v20_NEW37_EXTERNAL_AUTHENTIC_DYNAV5_CALIBRATED_AND_ORIGINAL_V17_3GEOMETRY_FINAL16_ONCE_NOY.py`.

The source 2D backbone is DAVIS-trained LowRankDynaCPI v5 (original two seeds, pretrained ESM2-650M and a molecular chemical prior). The 423D head input is 422D frozen v5 tower context + raw v5 affinity prediction. The 704D geometry descriptor uses ligand–pocket atom pair chemistry, Gaussian radial distances and bond/contact angular bases in native experimental bound structures. The residual MLP is 704→64→32→1 with LayerNorm and SiLU, producing a bounded `0.5 * tanh(raw_residual)`. Each old HiQBind349 source protein-group fourfold trains a three-seed LightGBM 2D calibrator and independently REAL/SHUFFLED/POCKET residual MLPs from equal seeded initial weights. Fixed training: 16 epochs, minibatches 32, AdamW lr0.001, weight_decay0.002, gradclip5; residual target `(observed pAffinity - inner-group-OOF 2D prediction)/fit-source-label-std`. The bundled `train.py` implements this from prepared features and frozen fold roles; **historical checkpoint identity additionally depends on original exact environment and input arrays**.

### Evaluation protocol

Primary V21: 37 originally source-selected native X-ray BioLiP3 PDB complexes, original exact-unit Ki/Kd read only after model predictions frozen. V22: 36 second cohort source records, 33 accepted by original strict numerical-parser eligibility; its source selection followed V21 but did not use new numeric labels. The two cohorts are **not independent assay databases**. Perceiver comparator: original upstream commit `755f076ef51099a90332fd1ec8437f94e3750c0b`, 4 source HiQBind349 TRAIN-only folds × 3 members × 150 epochs; different DAVIS pretraining and experimentally bound 3D access.

Source independent arithmetic and 5,000 protein-group MAE bootstrap checks were retained in the original archive. The post-hoc pooled 70 RMSE is computed as `sqrt((37*MSE_V21 + 33*MSE_V22)/70)`, not as mean of cohort RMSEs. Original true label orientation for Concordance Index is `pAffinity = -log10(molar Ki or Kd)`; higher is greater affinity. C-index/Pearson/Spearman were retrospective additions, and pooled C-index includes cross-cohort comparable pairs (not pooled from cohort C-index).

### First genuinely new external experimental source: OpenBind 2026

OpenBind EV-A71/CVA16 2A protease provided 925 original X-ray ligand–protein native-bound events in a source-independent assay campaign. All 925 were screened for SDF/PDB pose overlay, protein-heavy contact and covalent clash; 923 passed. After source-only compound chemistry and historical DAVIS/HiQBind/BioLiP3 scaffold overlap filtering, **660 source compound structures** and their **350 scaffolds** passed eligibility without numerical pKd. Exactly original source-trained DynaCPI v5 raw 2D, calibrated 2D, REAL/SHUFFLED/POCKET V17 residuals and the original unmodified DAVIS-pretrained 12-member PerceiverCPI ensemble all predicted those 660 cases, and the predicted values and original checkpoint hashes were frozen **before first source pKd access**. The source CSV `experimental_pKD` is already −log10(Kd in M); median finite measurements were used per original preselected compound group, yielding **482 measured cases from 264 scaffolds**. No model was fit to these new Kd outcomes.

- Raw DynaCPI v5 RMSE **0.8803**, C-index **0.5094**; original 12-model Perceiver RMSE **1.2885**, C-index **0.4658**; Dyna REAL native 3D RMSE **1.7986**, C-index **0.6640**.
- REAL versus SHUFFLED native-geometry paired C-index Δ **+0.03923**, descriptive 5,000-resample scaffold-cluster CI **[+0.02034,+0.05620]**. REAL versus POCKET-only paired MAE Δ **−0.11923**, CI **[−0.15222,−0.08936]**.
- But REAL versus SHUFFLED paired MAE Δ **−0.00286**, CI **[−0.03327,+0.03054]**, so the **prespecified primary criterion requiring a favorable MAE interval over both controls failed**. REAL also had **worse absolute pKd error** than raw v5 and original Perceiver; it overpredicted source mean affinity by ~**1.62 pKd units**.
- These outcomes belong to one 2A protease family with experimental bound poses supplied. They do not establish cross-protein-family generalization, prospective unbound candidate performance, equal ESM2/native-pose inputs, or an official PerceiverCPI paper benchmark victory. The source Kd values are now unsealed and **consumed**; future model adjustment on these same outcomes is exploratory, not a new blind test.

Frozen audit: `../DynaCPI-3D-RnD/geometry_v6_20261115/v50_OpenBind2026_single_target_new_Kd_native_strict_noY_20261117/` contains all before-score protocol, 660 source-only geometry/input/12-model checkpoint hashes, first numeric unseal log and aggregate-only scores. First score SHA256 `8df655770f5dacfcf2c59e9942008752a8e3f00fe40944393d5fe0e3c252a72e`. Public aggregate-only result `results/openbind2026_single_target_482_aggregate.json` and figure `figures/openbind-external-2026.png` contain no per-example Kd measurements.

### Independent scientific audit and raw-input reproducibility (V51)

**Completed 17 November 2026.** A new independent scorer—not importing the original V50 scoring function—re-read the already-released original OpenBind affinity CSV and the original, SHA-frozen noY prediction files. It reproduced all **54 metric values** across six model arms and all **12 confidence-interval endpoints** from four 5,000-draw scaffold-cluster contrasts (maximum CI numerical discrepancy **2.03×10⁻¹⁵**). Original 660 selected compound groups were verified to be **660 distinct canonical isomeric SMILES**; the 482 measured groups were **482 distinct isomeric SMILES**. Original per-group median pKd assignment matched exactly. No retraining, reselection or new test exposure occurred.

**Assay-row QC nuance found by the audit:** Of the 482 originally scored compounds, **four** had their numeric pKd only on other crystal/assay rows without the selected representative's full nonnumeric structural quality flags. The source-fixed V50 scoring rule explicitly aggregated all finite compound-group measurements, so the **predeclared 482-case results are unchanged**. A separately labeled **post-hoc** rowwise-QC-only 478-compound sensitivity retained the same qualitative findings: REAL−SHUFFLED C-index **+0.03997**, REAL−POCKET MAE **−0.11895**, and REAL−original Perceiver RMSE **+0.51455** (worse). This sensitivity is not a new blinded replication, and no post-hoc bootstrap CI was substituted for the original 5,000-draw study.

The clean repository now contains `predict_raw.py`, `src/dynacpi3d/raw_features.py`, and an exact copy of the original `geometry.py`. It accepts **SMILES + native experimental SDF + complex PDB** and derives original ESM2-650M, 423D DAVIS v5 features and REAL/SHUFFLED/POCKET 704D native geometry before applying the original HiQ349-fitted 4fold 3D residuals. In a new Python 3.11 CPU virtual environment with pinned original RDKit 2025.09.2, the **full original 660/660 raw OpenBind crystal compounds** (six receptor CA sequences) were successfully encoded again, with **zero** geometry/166D side feature difference and all five model outputs within maximum **0.01886 pKd** of the original frozen predictions (predeclared tolerance 0.03). No OpenBind numerical assay outcomes were accessed in these raw-input verification runs.

The fresh Python venv inherited globally available scientific packages, while fair-esm and RDKit were separately installed. It is **not** a proven fully isolated clean-room reinstall on a separate device. The original ESM/DAVIS weights and source349 training labels and checkpoints are still external and are never bundled into the public release. Raw ligand pose generation and full fresh backbone source retraining are not claimed. See [raw-input setup](RAW_REPRODUCIBILITY.md) and [aggregate proof](results/v51_scientific_audit_and_raw_reproducibility.json).

### Scope, negatives and leakage barriers

- On the historical BioLiP3 cohorts, REAL versus SHUFFLED geometry-specific MAE/C-index intervals include zero. On the new OpenBind single-target test, REAL versus SHUFFLED C-index confidence interval excludes zero in the favorable direction, but the primary MAE interval crosses zero. **Do not claim universal or fully causal native-distance benefit.**
- **V28 complete:** unmodified original Perceiver Git commit `755f076ef51099a90332fd1ec8437f94e3750c0b` trained **3 DAVIS members ×45 epochs** on the same 302-train-protein/20,536-pair DAVIS source supervision (59 DEV proteins/4,012 pairs) as Dyna, followed by **4 old HiQBind349 train-derived group folds ×3 members ×150 epochs**. All 12 checkpoints and both external source predictions (37+36, no numerical Ki/Kd Y) were SHA-frozen before retrospective scoring of the already-revealed n37+33 BioLiP3 assays. The full Perceiver RMSE on the post-hoc pooled 70 is **1.862432**, compared with Dyna REAL **1.318425** (49.89% less MSE); paired MAE difference −0.529739, *descriptive post-hoc* 5,000-cohort-stratified case-bootstrap 95% CI [−0.684968, −0.374058]. C-index **0.457036** versus REAL **0.728518**. These results are retrospectively derived and not equal input modality or ESM2 pretrained-protein-resource controls. The earlier V28A 1-member interim analysis is superseded as the primary DAVIS source-matched comparison.
- Native experimentally deposited **bound** poses make this a structural rescoring setting, not prospective pose-free chemical screening.
- Existing 2D-only DAVIS/KIBA/Metz held-out improvements must not be called new 3D wins. Paper's official fivefold data filters/splits have **not** been reproduced.
- **REAL versus SHUFFLED in the same Dyna backbone remains unresolved even after V28:** MAE ΔREAL−SHUFFLED = −0.01566, exploratory 5,000 paired case-bootstrap 95% CI [−0.05641,+0.02477]; pooled C-index Δ +0.01660, 95% CI [−0.00507,+0.03951]. These intervals cross zero; a strong causal 3D-distance effect has not been demonstrated.
- DockBind and PLINDER 2026-09 failed the predeclared >=30 structurally valid family-cold test eligibility gates. Their numeric affinity labels remain sealed.
- **No unblinded raw Ki/Kd, restricted old DAVIS81/HiQ75/ATOM3D tests, model checkpoints or dataset archives** are included here. `private/` and `runs/` are gitignored; do not commit such records.

### Reproduction levels

1. `python verify.py`: checks exact 47,361-parameter architecture and published cohort aggregate arithmetic, **not** per-row heldout Y.
2. `python verify.py --source-root ../DynaCPI-3D-RnD`: additionally verifies SHA-256 of the original immutable V21/V22 aggregate JSON plus the **five original V28/V41/V42 completion, frozen prediction, source-only scoring and fixed analysis-plan files**. It checks primary MSE values against source records and reads no raw assay outcomes.
3. `python prepare.py ...` / `python train.py --splits ...` / `python predict.py ...`: runs legitimate TRAIN349-only reconstruction and label-free inference from locally preserved features. **Verified here:** independent fresh TRAIN349 reproduction produced 12/12 original V17 REAL/SHUFFLED/POCKET checkpoint tensors **exactly equal** (all maximum tensor differences 0), and 37/37 real-3D native BioLiP3 *label-free* predictions exactly equal to the original pre-outcome-frozen V20 predictions (all max abs differences 0). These checks are SHA-audited in `results/prepared_feature_exact_replay.json`. This establishes exact **prepared-feature** reproducibility on the tested environment, not full raw-PDB/SMILES feature-generation reproducibility or general parity across other library/platform versions.
4. `python evaluate.py`: on a **new, authorized** label CSV chosen independently of model tuning; does not silently access reserved tests.

The protected original TRAIN349 labels, native experimental source input tensors and model checkpoint weights remain local under `private/` / `runs/` (gitignored), never inside the public ZIP. The released proof contains only aggregate checksums and counts. Core original manuscript and full reports remain in the preserved research clone, not duplicated into this concise repo.
